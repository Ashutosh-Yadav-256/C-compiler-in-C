Project Purpose & Vision

Why Build a Native C Compiler?

Developers use compilers every day without seeing what happens between source code and machine code. C-Compiler opens the black box of compilation, letting you explore the process step by step from lexical analysis and AST generation to IR, optimization, x86-64 assembly and execution.

Turning a Black Box into an Observable Pipeline

By building a native compiler from first principles in pure C without relying on Lex, Yacc, LLVM, or heavyweight compiler frameworks, C-Compiler exposes the underlying mechanics of compilation. It gives systems programmers, learners, and engineers transparency into memory arenas, semantic typing, TAC IR generation, flow-safe constant folding, and System V AMD64 ABI code generation.

Demystifying Compilation

Inspect every intermediate transformation in real time: lexical tokens, typed ASTs with scoped symbol tables, three-address IR, and emitted x86-64 NASM.

First-Principles Systems Engineering

Built without parser generators or heavyweight compiler frameworks. Geometrically chained bump arenas provide O(1) allocation with explicit lifetime management across translation units.

Compiler-Grade UX & Diagnostics

Detailed Rust/Clang-style error diagnostics with source-line pointers, unique error codes, and actionable hints make compiler failures easier to understand and debug.

Interactive Compiler & Runner Explorer

Write C code, compile to x86-64 assembly, inspect the IR / AST, and execute programs live with stdout capture.

Core Architectural Features

            
Engineered from first principles with zero-leak arena memory, robust epilogue routing, and System V AMD64 ABI compliance.

        


        

            

            

                
            

            
Dedicated Epilogues & Early Return

            
`IR_RET` branches directly to a dedicated `.L_epilogue` ensuring early returns inside nested `if/else` statements and recursive calls execute flawlessly.

        


        

            

                
            

            
Dynamic Chained Arena Memory

            
Eliminates per-node `malloc`/`free` overhead. Memory expands geometrically with chunk chaining and provides `arena_save()`/`arena_restore()` checkpoints.

        


        

            

                
            

            
True Type System & Pointers

            
Supports `int`, `char`, `void`, `long`, and pointer types (`T*`). Enforces lvalue validation and scales pointer arithmetic by base type sizes automatically.

        


        

            

                
            

            
Flow-Safe Optimization

            
Constant propagation and folding is strictly partitioned across basic block boundaries, preventing variable corruption across branching control flow.

        


        

            

                
            

            
System V AMD64 ABI Compliant

            
Transfers first 6 arguments via `rdi, rsi, rdx, rcx, r8, r9` with stack spilling, 16-byte stack frame alignment, and `al=0` for variadic C functions like `printf`.

        


        

            

                
            

            
Cross-Platform Validation & Safety

            
Automated regression test harness supporting Linux, macOS, and Windows with AddressSanitizer and UndefinedBehaviorSanitizer memory safety.
