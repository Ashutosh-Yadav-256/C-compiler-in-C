Core Architectural Features

            
Engineered from first principles with zero-leak arena memory, robust epilogue routing, and System V AMD64 ABI compliance.

        


        

            

            

                
            

            
Dedicated Epilogues & Early Return

            
`IR_RET` branches directly to a dedicated `.L_epilogue` ensuring early returns inside nested `if/else` statements and recursive calls execute flawlessly.

        


        

            

                
            

            
Dynamic Chained Arena Memory

            
Eliminates per-node `malloc`/`free` overhead. Memory expands geometrically with chunk chaining and provides `arena_save()`/`arena_restore()` checkpoints.

        


        

            

                
            

            
True Type System & Pointers

            
Supports `int`, `char`, `void`, `long`, and pointer types (`T*`). Enforces lvalue validation and scales pointer arithmetic by base type sizes automatically.

        


        

            

                
            

            
Flow-Safe Optimization

            
Constant propagation and folding is strictly partitioned across basic block boundaries, preventing variable corruption across branching control flow.

        


        

            

                
            

            
System V AMD64 ABI Compliant

            
Transfers first 6 arguments via `rdi, rsi, rdx, rcx, r8, r9` with stack spilling, 16-byte stack frame alignment, and `al=0` for variadic C functions like `printf`.

        


        

            

                
            

            
Cross-Platform Validation & Safety

            
Automated regression test harness supporting Linux, macOS, and Windows with AddressSanitizer and UndefinedBehaviorSanitizer memory safety.
